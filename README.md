# 휘슬! Whistle

스포츠클럽 리그전 경기 커맨드 센터입니다. 점수, 교체, 기록은 선생님 폰으로 하고, 학생은 QR로 실시간으로 봅니다.

만든 사람: 음악적체육인

## 화면

| 주소 | 누가 | 하는 일 |
| --- | --- | --- |
| `index.html` | 선생님 (구글 로그인) | 대회·학년·팀 명단·경기 만들기, 경기 진행 |
| `index.html?v=대회` | 학생 (QR, 로그인 없음) | 출전 명단, 지금 경기, 경기 결과, 순위표 |
| `index.html?b=대회` | 전광판 (로그인 없음) | TV·전자칠판에 띄우는 큰 점수판 |

## 할 수 있는 것

- 학년마다 종목과 규칙을 따로 정합니다. 기본 종목은 풋살, 축구, 넷볼, 농구, 배구, 티볼, 피구이고 직접 입력도 됩니다.
- 경기 방식: 전·후반, 쿼터, 한 번에, 세트, 이닝, 피구(세트 시간 + 전원 아웃).
- 득점할 때 선수를 고르고, 교체할 때 누가 나가고 들어갔는지 기록에 남습니다. 교체 카드는 자동으로 셉니다.
- 초대 코드로 다른 선생님을 심판으로 초대합니다. 초대받은 선생님은 경기 진행만 할 수 있습니다.
- 개인 기록은 선생님만 보고, 전광판에 띄울 때만 학생에게 보입니다.

## 파일

- `js/logic.js` 경기 규칙 계산 (화면·저장과 떨어져 있음)
- `js/store.js` 저장. 파이어베이스 실시간 DB 또는 미리보기(기기 안 저장)
- `js/app.js` 화면
- `js/config.js` 파이어베이스 설정. `databaseURL` 이 비어 있으면 미리보기로 열립니다.
- `firebase-rules.txt` 실시간 DB 보안 규칙. 파이어베이스 콘솔의 Realtime Database > 규칙에 붙여 넣습니다.

## 시험

```
node tests/check.mjs          # 코드 검사: 문법, 단추가 부르는 기능, 판 번호
node --test tests/logic.test.mjs   # 경기 규칙 시험
node tests/e2e.mjs            # 전체 시험: 화면을 띄워 선생님·학생·전광판 흐름을 밟아 봄 (playwright 필요)
```

단순 수정(글귀·색·여백)은 코드 검사만, 기능 수정은 세 가지를 모두 돌립니다.
